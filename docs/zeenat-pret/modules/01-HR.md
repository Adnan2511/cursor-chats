# Module 01 — HR (Human Resources & Payroll)

**Company:** Zeenat Pret  
**Module:** HR  
**Version:** 1.0  
**Depends on:** Employee Master, Attendance Devices/Manual Entry, Accounts (salary & advance posting)  
**Feeds to:** Accounts (salary expense, advances, deductions), Production (worker identity for piece-rate where linked)

---

## 1. Purpose

Manage complete employee lifecycle for Zeenat Pret: registration, enrollment, shifts, daily attendance, payroll, corrections, advances, PF, annual leaves, increments, allowances, performance, and full history.

---

## 2. Scope

| In scope | Notes |
|----------|-------|
| Employee registration / enrollment | Permanent, temporary, piece-rate staff as configured |
| Shift management | Morning / evening / custom shifts |
| Daily attendance | Present, absent, late, half-day, leave, holiday |
| Attendance correction | Authorized correction with audit |
| Payroll / salaries | Monthly salary calculation |
| Advance salary | Request, approval, recovery |
| PF (Provident Fund) | Contribution tracking per employee policy |
| Annual leaves | Accrual, request, approval, balance |
| Increments | Salary revision history |
| Allowances | Fixed / variable allowances |

## 3. Employee Registration / Enrollment

### 3.1 Required Fields

| Field | Required | Notes |
|-------|----------|-------|
| Employee Code | Auto | Unique |
| Full Name | Yes | |
| Father / Husband Name | Optional | As per company form |
| CNIC / ID | Yes if required by management | Unique when provided |
| Mobile | Yes | |
| Address / City | Optional | |
| Date of Joining | Yes | |
| Department | Yes | Production, Store, Outlet, Accounts, Admin, etc. |
| Designation | Yes | |
| Employment Type | Yes | Permanent / Contract / Daily wages / Piece-rate |
| Shift | Yes | Default shift |
| Basic Salary / Wage Type | Yes | Monthly / Daily / Piece |
| Bank Account / Payment Mode | Optional | Cash / Bank |
| Emergency Contact | Optional | |
| Documents | Optional | CNIC copy, photo, contract |
| Status | Yes | Active / Inactive / Left |

### 3.2 Enrollment Rules

- Employee code never reused for another person.
- Inactive employees cannot mark attendance or receive new payroll runs (pending settlements still allowed).
- Piece-rate stitchers/press/packing may also exist in Worker Master used by Production/Accounts; system should allow single person record linked to both HR and Worker Payable where applicable.

## 5. Daily Attendance

### 5.1 Capture Methods

- Manual entry by HR / Supervisor  
- Bulk import (Excel)  
- Biometric / device integration (optional phase)  

### 5.2 Attendance Statuses

Present | Absent | Late | Half Day | On Leave | Holiday | Weekly Off | Missing Punch

### 5.3 Rules

- One attendance row per employee per date.
- Late calculated from shift start + grace.
- Missing punch flagged for correction.
- Production floor piece workers may still use production qty for wages; HR attendance remains for control/present days where management requires both.

---

## 6. Attendance Correction

| Rule | Detail |
|------|--------|
| Who | HR Officer / Manager (role permission) |
| What | Change status, in/out time, remarks |
| Audit | Old value, new value, user, date/time, reason mandatory |
| Lock | After payroll period lock, correction requires Admin unlock |

---

## 7. Payroll / Salaries

### 7.1 Salary Components

| Component | Type |
|-----------|------|
| Basic salary | Earning |
| Allowances (house, conveyance, other) | Earning |
| Overtime | Earning |
| Bonuses / incentives | Earning (if approved) |
| Attendance deduction | Deduction |
| Advance recovery | Deduction |
| PF employee contribution | Deduction |
| Other deductions | Deduction |
| Net payable | Auto |

### 7.2 Calculation Inputs

- Employee salary structure  
- Attendance summary for period  
- Approved leaves  
- Advances outstanding  
- Increment effective date  
- Allowance assignments  
- Piece-rate / weekly job-work settlements already paid via Accounts (must not double-pay; link or exclude by employment type)

### 7.3 Payroll Flow

1. Select period (month)  
2. Pull attendance + components  
3. Generate draft payroll  
4. HR review / adjustments with remarks  
5. Manager approve  
6. Post to Accounts (salary expense + payable / payment)  
7. Generate payslip (PDF)  
8. Mark paid (Cash / Bank)  

---

## 8. Advance Salary

| Step | Requirement |
|------|-------------|

- [ ] Full employee history available on one screen
